MovieEncoder for Nissan Navi 取扱説明書

一般的な動画ファイルを、日産純正カーナビ MM521D-L 向けの MP4 へ一括変換するソフトです。

バージョン 1.0 / 対応OS: Windows 11

1このソフトについて

お手持ちの動画（mp4・mkv・avi・mov など）を、カーナビ MM521D-L で再生しやすい形式（H.264 / 1280×720 の MP4）へ まとめて変換します。難しい設定は不要で、ファイルをドラッグ＆ドロップして 「変換開始」を押すだけです。

はじめにお読みください（重要）
標準の出力設定は MM521D-L で一般的に再生しやすい値ですが、 すべての映像が実機で再生できることを保証するものではありません。 もし再生できない場合は、プリセットを Safe/Compat（互換フォールバック） に変えてもう一度変換してください （詳しくは 11. 困ったときは）。

2導入（インストール）

本ソフトはインストール不要のポータブル版です。

  1. ZIP を展開する 配布された MovieEncoderForNissanNavi-1.0-win-x64-portable.zip を、 書き込みできる任意のフォルダ（例: デスクトップやドキュメント）へ展開します。
  2. exe を起動する 展開したフォルダ内の MovieEncoderForNissanNavi.exe をダブルクリックします。
ポイント
設定ファイル（config.json）と既定の出力先フォルダ（output）は、 exe と同じフォルダに作られます。フォルダごとコピーすれば設定も一緒に持ち運べます。
注意： C:\Program Files など書き込み制限のある場所には展開しないでください。 設定や出力の保存に失敗することがあります。

3画面の構成

場所内容
上部ツールバープリセット選択 / 同時実行数 / 「変換開始」「停止」「ログ保存」「全てクリア」
登録エリア（点線の枠）動画やフォルダをドラッグ＆ドロップ。「ファイルを選択」ボタンでも追加可能。
ファイル一覧登録した動画の名前・メディア情報・状態・進捗・残り時間・削除ボタン。

4基本的な使い方

  1. 動画を登録する 変換したい動画ファイルを登録エリアにドラッグ＆ドロップします。 フォルダごとドロップすると、そのフォルダ直下の対応動画をまとめて登録します （サブフォルダの中までは取り込みません）。「ファイルを選択」ボタンからも追加できます。
  2. メディア情報を確認する 登録すると、各行に解像度・コーデック・フレームレート・再生時間が自動表示されます。 読み取れないファイルは メタ取得失敗 と表示されますが、そのまま変換は試行できます。
  3. プリセットと同時実行数を選ぶ 通常は Nissan MM521D-L（標準） のままで構いません （5. プリセット 参照）。
  4. 「変換開始」を押す 押すと必ず出力先フォルダの選択ダイアログが表示されます。保存先を選んで決定してください。
  5. 完了を待つ 各ファイルが 待機中 → 変換中 → 完了 と進みます。 すべて終わると完了ダイアログと Windows 通知が表示されます。
ヒント： 途中で 1 つの動画がエラーになっても、残りの動画の変換はそのまま続行されます。

5プリセットの選び方

プリセット特徴こんなときに
Nissan MM521D-L（標準） 互換性重視。H.264 High / 720p / 平均4000kbps。 まずはこれ。迷ったら標準。
高画質 画質優先（CRF18・音声192k）。変換は遅め・容量大きめ。 画質を上げたいとき。
高速変換 速度優先。画質は少し落ちる。 大量の動画を素早く変換したいとき。
Safe/Compat（互換フォールバック） Main / Level3.1・低めビットレートの保険設定。 標準でナビが再生してくれないとき。
設定を細かく変えたい方へ： プリセットの数値は （アプリフォルダ）/resources/app.asar.unpacked/... ではなく、 ソース配布の src/shared/presets/*.json を編集して再ビルドすることで変更できます （技術者向け。詳細は同梱の README / 設計書を参照）。

6同時実行数

一度に何本の動画を並行して変換するかを 1〜8 の範囲で選べます（初期値 3）。

  • 数を増やすと全体が速く終わる場合がありますが、パソコンの負荷が高くなります。
  • 動作が重いと感じたら 1 や 2 に下げてください。

7出力先とファイル名

出力先

「変換開始」を押すと毎回フォルダ選択ダイアログが出ます。既定はアプリフォルダ内の output フォルダです。選んだ 1 つのフォルダに、登録した全ファイルが出力されます。

ファイル名のルール

  • 拡張子は .mp4 になります（例: 旅行.mkv → 旅行.mp4）。
  • 出力先に同じ名前がある場合のみ、旅行 (1).mp4、旅行 (2).mp4 と番号が付きます。
  • 元のファイルや既存ファイルを上書きすることはありません。
安全設計： 変換中は一時ファイルとして書き込み、成功したときだけ正式名に変わります。 途中で停止・失敗した場合の壊れた一時ファイルは自動で削除され、出力フォルダに残りません。

8停止・キャンセル

  • 個別キャンセル： 一覧の各行の「削除」は待機中のみ可能です（変換中の行は削除できません）。
  • 全体停止： 変換中はツールバーのボタンが「停止」に変わります。押すと実行中の変換を止め、待機中のものも中止します。

停止した場合は 中止 と表示され、完了ダイアログには「変換を中止しました」と出ます。

9ログの確認と保存

  • 右側のログ領域に、変換エンジン（ffmpeg）の出力がリアルタイムで表示されます。
  • ファイル一覧の行をクリックすると、その動画のログだけに絞り込めます（「✕ → 全て」で解除）。
  • ツールバーの「ログ保存」で、表示中の全ログをテキストファイル（UTF-8）に保存できます。
うまくいかないとき： エラーになった動画はログにエラー内容（英語）が残ります。 原因の切り分けに役立つので、お問い合わせ時はログを保存して添えてください。

10ナビ（MM521D-L）での再生方法

  1. USB メモリを用意するFAT32 でフォーマットした USB メモリを推奨します。
  2. 変換した MP4 をコピーする出力フォルダの .mp4 を USB メモリへコピーします。
  3. 車両の USB 端子に挿すナビの USB / メディア入力に接続します。
  4. ナビで動画ソースを選ぶナビの「USB 動画」などのソースから再生します。
再生できないときは：
  • プリセットを Safe/Compat にして変換し直す。
  • ファイル名を半角英数の短い名前にしてみる（機種により長い名前や記号が苦手なことがあります）。
  • 1 フォルダに入れるファイル数を減らす。

11困ったときは（FAQ）

Q. 変換した動画がナビで再生できません。

A. プリセットを Safe/Compat（互換フォールバック） に変えて変換し直してください。 それでも再生できない場合は、ファイル名を短い半角英数にする・USB を FAT32 で再フォーマットする等もお試しください。

Q. 「メタ取得失敗」と表示されます。

A. ファイルが壊れているか、特殊な形式の可能性があります。そのまま変換を試すことはできますが、 失敗する場合はエラーとして表示され、他のファイルの処理は継続されます。

Q. エラーになる動画があります。

A. 主な原因と表示は次のとおりです。

表示主な原因・対処
ディスク容量不足の可能性があります出力先ドライブの空き容量を確保してください。
書き込み権限がない可能性があります書き込みできるフォルダを出力先に選んでください。
ファイルが破損しているか、対応できない形式です元ファイルが壊れていないか確認してください。
変換に失敗しました（詳細はログを参照）ログを保存して内容を確認してください。

Q. 変換がとても遅い／PC が重いです。

A. 同時実行数を 1〜2 に下げる、または「高速変換」プリセットを使ってください。

Q. 元の動画は消えますか？

A. 消えません。本ソフトは新しい MP4 を作るだけで、元ファイルは変更も上書きもしません。

Q. 同じ名前の動画を変換するとどうなりますか？

A. 出力先に同名がある場合のみ、自動で (1) (2) と番号を付けて保存します。上書きはしません。

12仕様・制限事項

標準出力仕様（Nissan 標準プリセット）

項目値
コンテナMP4（faststart）
映像H.264 (libx264) / High Profile / Level 4.0 / yuv420p
解像度1280×720（アスペクト比維持・黒帯）
フレームレート29.97fps
映像ビットレート平均 4000kbps
音声AAC-LC / 48kHz / 128kbps

対応入力形式

mp4 / mkv / avi / mov / wmv / flv / m4v / ts / mts / m2ts / webm

制限事項（v1）

  • GPU エンコード非対応（CPU での変換のみ）。
  • 対応 OS は Windows 11 のみ（macOS 非対応）。
  • プリセットの画面上での編集はできません。
  • 実機 MM521D-L での再生は保証外です（互換性は最終的にユーザー側でご確認ください）。
